# Employee Hierarchy

A web app for managing EPI-USE Africa's employees and reporting structure, built as a technical assessment.

Live site: coming soon

## Features

- Create, view, edit and delete employees
- Set each employee's reporting line manager
- Interactive org chart with search
- Employee table with sorting and filtering on every field
- Gravatar avatars, with optional photo upload
- Departments
- CSV import and export
- Deleting a manager lets you choose where their direct reports go
- Dashboard with headcount and salary stats
- Admin login to protect the data

## Tech stack

- Frontend: React, TypeScript, Vite, Tailwind CSS, shadcn/ui, TanStack Query and Table, React Flow
- Backend: Python, FastAPI, SQLAlchemy, Alembic
- Database: PostgreSQL on Amazon RDS
- Hosting: AWS , Docker, GitHub Actions
