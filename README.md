## Features

**Employees**

- Create, view, edit and delete employees
- Set each person's reporting line manager
- An employee cannot be their own manager, and cannot report to anyone below them in the chain
- Employees may have no manager, so the organisation can have more than one person at the top
- Employee numbers generated by the database

**Viewing the organisation**

- Interactive org chart with collapsible teams, search, and a details panel showing the full
  reporting line
- Table with sorting on every column, faceted filters for department, role and manager, salary
  and date ranges, and column visibility

**Data**

- CSV import with per row validation
- CSV export of the filtered view
- Departments with colour coding
- Dashboard with headcount and salary figures

**Profile pictures**

- Gravatar, matched on the employee's email address
- Optional photo upload to Amazon S3, shown in place of the Gravatar

**Platform**

- Administrator login, bcrypt hashed passwords, rate limited attempts
- HTTPS on a custom domain, security headers, database with no public access
- Automated tests and continuous deployment

## Running locally

Requires Docker, Node 22 and [uv](https://docs.astral.sh/uv/).

```bash
git clone https://github.com/DandreNel7/employee_hierarchy.git
cd employee_hierarchy
docker compose up -d                 # PostgreSQL, and MinIO for photo uploads
```

**Backend**

```bash
cd backend
cp .env.example .env                 # then set JWT_SECRET
uv sync
uv run alembic upgrade head
uv run python -m app.scripts.create_admin
uv run fastapi dev app/main.py
```

**Frontend**

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173 and sign in with the administrator account you created. To load the
sample organisation, use **Employees > Import** and choose `samples/employees.csv`.

## Tests

```bash
# backend
docker exec epi-use-db-1 psql -U employee -d postgres -c "CREATE DATABASE employee_hierarchy_test;"
cd backend
DATABASE_URL=postgresql+psycopg://employee:employee@localhost:5432/employee_hierarchy_test uv run pytest

# frontend
cd frontend
npm test
```

Tests covering the hierarchy rules, login, and the helpers behind the chart and CSV handling.

## Deployment

Every push runs lint, tests and a production build. A successful run on `main` builds both
Docker images, pushes them to Amazon ECR and updates the instance. Database migrations are
applied when the API container starts.

---

## A note on the data

`samples/employees.csv` contains sample data in the format the import feature expects. The live
system was populated by importing this file through the application. The application itself
reads no data from files and holds no hardcoded records, every change is written to the
PostgreSQL database on Amazon RDS.
